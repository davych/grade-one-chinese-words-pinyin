# 语文练习册

根据教材照片整理的一年级语文练习册，按 **语文园地一至八** 选择章节和课次。单个 HTML 内嵌全部样式、脚本、拼音、范字和笔顺数据，可离线使用，适合 A4 打印。

**[在线使用](https://davych.github.io/grade-one-chinese-words-pinyin/)** · [使用说明](使用说明.txt)

## 两种练习

- **识字表 · 写拼音**：280 个生字，另保留教材蓝色标注的 4 个补充读音，共 284 个练习项。一字一个拼音田字格，屏幕可以显示或隐藏拼音，打印时拼音栏始终留空。
- **写字表 · 练写字**：100 个汉字，一字一行。默认 18 mm 田字格，首格预填范字，其余 9 格为空白。支持显示逐笔图示及播放笔顺。

## 按章节打印

需要复习错字时，将左侧“练习内容”切换为 **错字加练 · 手工输入**，输入汉字即可实时生成练习。选择“写拼音”或“练写字”后直接打印，也可打印两类。保留输入顺序和重复字，忽略空格、标点；每次最多输入 200 字符。内容仅留在当前页面，刷新后清空。教材外汉字可打印，但没有拼音和笔顺提示；多音字显示教材收录的读音。

1. 点击园地按钮进行多选，再点一次取消。可以组合任意园地，或使用“全选园地 / 清空园地”。
2. 勾选具体课次；课次栏的“全选”选择所选园地全部内容，“仅园地”只选择园地自身条目，“清空”只清除所选园地、当前练习类型的课次选择。
3. 切换识字表或写字表时，共用所选园地，两类各自保留课次选择与随机排列。
4. “打印当前练习”打印当前类型已选内容；“打印两类”统一打印所选园地中两类各自勾选的内容，并保持各自当前的汉字顺序。

每章包含对应园地之前的课次和园地本身。例如园地一包含识字第1—4课及园地一的识字内容；写字表没有识字第1课的写字条目，因此从第2课开始。写字表园地二、三、四各只有2字，与教材一致。教材顺序下，每章另起一页。

## 随机复习

选好园地和课次后，点击“随机打乱”，会将当前练习类型的已选汉字跨园地、跨课次混合排列。再次点击会生成新的顺序；“恢复教材顺序”可还原。

屏幕和打印使用同一份已保存的排列，打印预览、重复打印、格子大小、姓名、拼音或笔顺开关均不会重新打乱。两种练习分别保存自己的排列，“打印两类”按各自当前顺序输出。

改变园地范围后，两类恢复教材顺序；改变课次勾选后，当前类型恢复教材顺序。重新加载网页也恢复默认状态。随机练习会标注每个字的原园地/课次，保留多音字的不同读音条目。

打印选择 **A4、纵向、100% 缩放**，关闭浏览器页眉和页脚。默认不打印笔顺图；需要时勾选“打印时附带笔顺图”。可改为20 mm大格，每行9格。

## 本地使用与修改

直接用浏览器打开 `index.html`；只复制此文件也可以离线使用，无需安装。

数据在 `data/words.json`。两种练习各有8个 `Groups`，每组保留 `lessons`，每课包含 `items`。字形和笔顺位于 `data/strokes.json`，页面模板位于 `tools/index.template.html`。

修改后用 Python 3 运行：

```sh
python3 -m unittest discover -s tests -v
python3 tools/build.py
```

只使用 Python 标准库；日常使用练习册无需 Python。测试按照片转录的逐课字序检查分组、字数、多音字和字形数据覆盖。

## GitHub Pages

推送到 `main` 自动运行 [Deploy GitHub Pages](https://github.com/davych/grade-one-chinese-words-pinyin/actions/workflows/deploy-pages.yml)，也可手动触发。工作流检查教材数据、重新生成并校验 HTML，然后仅发布成品与数据许可证。

## 字形与笔顺许可

字形和笔顺来自 [Hanzi Writer Data](https://github.com/chanind/hanzi-writer-data) / [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)，覆盖全部280字。数据遵循 [Arphic Public License](data/ARPHICPL.TXT)，许可证已内嵌 HTML。版本及来源详见 [笔顺数据来源](data/笔顺数据来源.txt)。

本机教材转录中间文件、截图和打印检查 PDF 保留在 `检查/`，不提交仓库。教材照片没有上传至网站或仓库。
